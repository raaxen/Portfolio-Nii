# NiiFita

Portfolio web React, TypeScript et Tailwind CSS.

## Demarrer

```bash
npm install
npm run dev
```

Vite affiche l'adresse locale dans le terminal.

## Build

```bash
npm run build
```

Les composants se trouvent dans `Screens/` et `components/`. Tailwind prend en charge les variantes responsive comme `md:`. Les liens et leurs icones mobiles sont configures dans `data/navbar.ts`.
